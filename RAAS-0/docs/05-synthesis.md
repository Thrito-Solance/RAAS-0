## 2. Identity boundary (where constraints end and the entity begins)

The minimal core, common to all four source frameworks. Subtract any one and the project stops being this project:

1. **Historical memory** — the Directed Assembly Index AI ∈ ℕ: structure defined by construction history, not instantaneous state.
2. **The reflexive operator γ** — a sub-graph fixed point acting on the system containing it.
3. **Quantized monadic cost** — F_R(μ) ≻ 0. The subtraction threshold: remove it and the framework collapses back into ordinary Constructor Theory — precisely the idealisation the Phase-2 red team rejected.
4. **Partial composition over a resource lattice** — g∘f defined iff the joined cost is within the local sheaf bound, else 0_Res.

Everything else is extension. Conversely, only RAAS is defined by its paraconsistent machinery: removing the Borromean condition dissolves RAAS entirely while leaving the other three frameworks intact.

## 5. Minimal fatal inputs (ranked)

1. **Resource slack zeroed** — one perturbation forcing F_R(μ) ⪯̸ R_X(U_causal) → 0_Res. Instant, global, no warning ramp. The single smallest dismantling input in the framework.
2. **Third-loop cut** — γ_i → 0_Res → det(M_Δ) → 0 → local logical explosion. Low probability, total local collapse; contained by design.
3. **Decoder backlog** — T_μ > Δt_coherence: noise outruns μ. The slow-burn variant of input 1 (cases/agi-compute-cliff.md, cases/surface-code-backlog.md, cases/neuromorphic-thermal-wall.md).
4. **Boundary coincidence** — δ_θ → 0° → Λ_∅ diverges → the Closure Horizon annihilates the void (docs/02-absence.md §5).

No fatal input operates through the assembly index itself: memory is the most robust stratum; cost is the most fragile. The identity is durable; the continuation is not.
