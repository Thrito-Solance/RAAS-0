# The Method Charter — docs/00

RAAS-Ø is not built by adding frameworks together. It is built by subtracting what they cannot be, holding what they contradict, and containing what would otherwise explode.

## 1. Via negativa (first-principles subtraction)

Every element of the corpus was evaluated by the following operative questions:

- What must this not be, given what it cannot be?
- What should be there, but isn't?
- What is there, but shouldn't be?
- What is entirely defined by its absence?
- What is broken, but keeping the system alive?
- Which "noise" has become a load-bearing pillar?
- What is the single smallest, lowest-probability negative input that completely dismantles the positive structure?
- Where do the constraints end and the entity begin?
- At what point does subtracting a feature change the identity of the system entirely?

Subtractions performed on the corpus are recorded in docs/05-synthesis.md §6. Nothing is removed silently.

## 2. Dialetheism

Contradictions within the corpus are treated as true (A ∧ ¬A), not as errors, gaps, or stages awaiting resolution. The framework's five constitutive dialetheias (D1-D5) are enumerated in docs/05-synthesis.md §3 and are permanent fixtures: they are not stepping stones to a synthesis — they are the synthesis.

## 3. Paraconsistent composition (non-Hegelian)

The synthesis is not an Aufhebung. No framework is sublated into a "higher" unity; each retains its boundaries, and the composite is the non-explosive structure that holds them together while they disagree.

Two rules govern composition:

1. **No explosion** (ex falso quodlibet is rejected): a true contradiction does not entail everything. The system remains locally rigorous where it contradicts itself.
2. **Localisation**: every dialetheia is localised to a tripartite Borromean node Δ(A, B, C). A contradiction is inert unless bracketed by a third component. Remove the third loop and the node undergoes local — never global — logical explosion (docs/04-paradox.md).

## 4. Intake protocol

Any incoming element is processed as follows:

1. **Audit** — what is present but shouldn't be; absent but should be; broken but load-bearing.
2. **Dialetheia classification** — does the element contradict a standing claim? If so, it is held, not arbitrated.
3. **Identity check** — does it touch one of the four identity-preserving axioms (docs/05-synthesis.md §2)?
4. **Subtraction** — noise is removed and its removal is recorded.
